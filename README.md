# 🧠 Java Quiz Game – Two-Person Interactive Game

This project was a Java-based interactive quiz game developed using Object-Oriented Programming and GUI design with **Java Swing**. It allowed one player to create a custom quiz by entering their name, the number of questions, and corresponding answers. The second player would then attempt to answer these questions in a game-like environment.

## 🎮 Game Overview

- The first player entered:
  - Their **name**
  - The **number of questions**
  - The **questions and correct answers**
  
- The second player then played the game by answering those questions.
- Each **correct answer** awarded points.
- Each **incorrect answer** deducted points.
- If the score dropped below a certain threshold, the player **lost the game**.

## 🛠 Technologies Used

- **Java (OOP)**: Core logic, question handling, and scoring system
- **Java Swing**: GUI interface for question input, gameplay, and score display

## ✨ Key Features

- Custom quiz creation from Player 1
- Score-based feedback for Player 2
- Win/Lose logic based on the total score
- Graphical user interface with interactive elements
- Dynamic question handling using ArrayLists or similar structures
